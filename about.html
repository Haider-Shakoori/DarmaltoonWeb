About

Building pharmacy software for real environments

Darmaltoon’s mission is to build modern pharmacy-management software suitable for real pharmacy environments.

What we focus on

  • Modern technology — a professional desktop application experience.
  • Local usability — designed for pharmacies in Afghanistan.
  • Multilingual access — English, Dari and Pashto.
  • Pharmacy-focused workflows — built around pharmacy operations, not generic accounting.
