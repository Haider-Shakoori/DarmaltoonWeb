Frequently asked questions

Can Darmaltoon work without internet?

It is designed for offline-first Windows use. Some synchronization and license-related functions may require connectivity, depending on the installed configuration.

Which languages does Darmaltoon support?

English, Dari and Pashto, including right-to-left interface support.

Is this an online-only web pharmacy system?

No. The main product is a Windows desktop pharmacy management application. This website introduces the product and accepts demonstration inquiries.

How much does Darmaltoon cost?

Request a demonstration to ask about current licensing and deployment options. Prices are not published on this page.
